# <p align=center>HTML Gaming - Amour Sucré Like</p>


## ✨ Amour Sucré Like c'est quoi ?

Amour sucré like, est un jeu Web inspiré du jeu **[Amour Sucré](https://www.amoursucre.com/)**.  
C'est un jeu narratif, créé dans le câdre d'un projet d'étude *Epitech*.
